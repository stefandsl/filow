Filow: помощник выступающего, который слушает вас во время презентации.
Загрузите сценарий и говорите свободно: Filow отмечает пункты, как только вы о них расскажете, и показывает, что вы пропустили. Зеркало на телефоне, Screen Sense и надстройка PowerPoint.

Локальный или облачный ИИ: на следующей странице выберите модели, которые будут скачаны при первом запуске. Без локальных моделей Filow использует облако: ключ API OpenRouter (несколько центов за выступление), его нужно вставить в файл .env, который приложение откроет при первом запуске. В автономном режиме по сети ничего не отправляется.


ЧТО НОВОГО

Все версии: https://github.com/stefandsl/filow-releases/releases
Сообщить о проблеме: в Filow откройте меню Filow > «Сообщить о проблеме». Filow сохраняет файл отчёта, который вы отправляете сами, не публикуя его; само приложение ничего не отправляет.

# Filow 0.9.30

* Установщик: страница «Информация» с описанием новых возможностей и страница выбора компонентов с размерами и типами установки (рекомендуемая для этого компьютера, полная, минимальная).

# Filow 0.9.29

* Синхронизация с телефоном: повторные и устаревшие обновления игнорируются; после разрыва или переподключения передаётся полное состояние.
* При остановке прогона последние слова больше не теряются.
* У оверлея выступающего появились полоса для перетаскивания и крестик для закрытия.

# Filow 0.9.28

* Выбор микрофона рядом с кнопкой «Начать прогон» и в настройках, с предупреждением, если выбранный микрофон не передаёт звук.
* Загрузка локальной модели распознавания речи теперь повторяется, а не зависает.
* Автономный режим: перевод, токены распознавания, скачивание моделей, публичный туннель и отчёты о проблемах больше не используют сеть.

# Filow 0.9.27

* Единая компоновка для тёмной и светлой темы: разделы на боковой панели, следующий раздел под пунктами, Screen Sense над панелью запуска.

# Filow 0.9.26

* Хорошо заметная зелёная галочка на озвученных пунктах.
* Окно подключения остаётся открытым при переходе на публичную ссылку.
* Размер панели «Следующий раздел» меняется перетаскиванием её края.

# Filow 0.9.25
