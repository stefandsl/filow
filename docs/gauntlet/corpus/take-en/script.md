# Intro - What is a decision model?
- A new kind of AI that outputs a decision, not words
- It can't talk, can't call tools, can't search the web
- Everyone is copying it, so it must be good

# PART I - What is it? What's the difference?
- Paste the same thing into ChatGPT
- It is faster because it just makes a decision
- Only three answer types: yes or no, multiple choice, and a score
- ChatGPT can give a simple answer too, but it's still slower
- LLMs were built to talk to us, this was built different
- It talks to code, not to you

# PART II - Who is this for?
- It's for developers, and we're all developers now
- Your AI agent only needs to understand it, you don't
- Model routing: small, medium or large model picked in milliseconds

# Demo - Filow
- Live transcription, checked every half second
- It checks the idea, not the exact words
