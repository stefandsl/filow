# Filow | Speak freely. Stay on point.

Someone who struggles to explain an idea should be able to share it by talking. That person might be teaching science, showing a colleague how to use an app, or trying an AI assistant for the first time. Give them one place to start, a visible mic state, and a way to type, correct or stop.

**On stage.** A presenter can use a nearby or Bluetooth mic, take a question, and see what they covered, missed and should say next on desktop and phone. Filow can show a photo, draw a diagram and open an approved lesson site. It can point to a control in the active window, explain what it changes, wait for the presenter and check the result before resuming the talk. Live captions help listeners follow in another language and demonstrate what they learned.

**At a desk.** Day-by-day turns dictated plans into editable tasks. The user can report progress in their own words, correct a mistaken completion and choose the intended task when the reference is ambiguous. Unfinished work carries over. Speech from a lecture or call leaves the list untouched. Microsoft To Do, Planner and Outlook are design references. List connections are optional.

**What understands speech.** A decision model quickly chooses a task, finds photos with formulas or selects a diagram. A teaching model uses those choices and checks the explanation against the screen. Compare Liquid d1 with alternatives on real speech and hardware. Show the active model and one suitable option. Reuse compatible model weights in place. Offer larger models when measured performance supports running them alongside the mic and deck.

**Who is in control.** The desktop UI, local CLI, MCP and user-defined workflows share a session and a permission model. Compatible clients can request permitted actions. Users can describe a workflow by voice and edit each step. Demanding work can use an approved cloud provider. Private mode uses supported local compute. Before a sensitive action or transfer, Filow shows the target, recipient and data. It signals actual transfers and lets the user take over immediately. Later work will assess two-way masking for text, audio, photos and video.

The first proof is a packaged lesson a learner understands and a daily list the owner uses the next morning. Each earns its own result. The public promise starts at a verified installer download. [Delivery plan](PLAN.md)
