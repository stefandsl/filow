# Handoff: Filow bug hunt and fixes

For the next agent working on this codebase. Read this first.

## What was done
1. Unpacked the user's `filow-main.zip`. The original upload was not modified.
2. **Bug hunt.** All 102 non-test TS/JS source files (13,222 lines) were split into 12 slices. Each slice was read line by line by one agent, then re-read by an independent reviewer looking for anything missed. Together they produced 134 suspicions.
3. **Proof.** Each of the 38 suspicions rated ≥3/5 went to a separate prover, which tried to write a failing test. A rejected claim got one more attempt from a fresh prover.
   - 33 were confirmed: 21 with a failing test, 12 by reading the code path.
   - 5 were rejected (see `bug-report.md`).
4. **Fixes.** All 33 fixes were applied to a working copy and committed in one commit.
   - The full diff is in `fixes.patch`: 21 files, +125/−47.
   - To apply it, run `git apply fixes.patch` from the repo root.

## Files in this output folder
- `bug-report.md`: every confirmed bug with location, input, expected vs actual behaviour, severity and fix, plus the rejected ones.
- `fixes.patch`: the code changes. Each change is small and placed where the bug is.
- `tests/bugN/`: the proving test and its output for each bug that was demonstrated by a test. Bug numbers match the report.

## How much the fixes were checked
- **Fixes the prover verified:** bugs 3, 4, 6, 7, 8, 10, 14, 17, 19, 20, 21, 23, 24, 27, 29, 33, 34, 35, 36, 37.
  - For each of these, the prover's test passed on a patched copy.
  - Most of those tests ran against faithful copies or extracts of the code, because the repo has **no `node_modules`**.
- **All edited files:** after patching, every edited file passes `node --check` (JS) or a TypeScript transpile syntax check.
  - **No full typecheck or test suite was run**, because dependencies are not installed.
- **Fixes not verified by a prover:** bugs 1, 2, 5, 9, 13, 15, 18, 22, 25, 26, 28, 30, 31.
  - These are mostly Electron, Office, React or browser code that can't run here.
  - The fixes follow from reading the code but need a check in the real runtime.

## Suggested next steps
1. `npm install`, then run the repo's typecheck and existing tests against the patched tree.
2. Turn the tests in `tests/` into real tests in the repo's test framework. Several of them currently stub dependencies.
3. Check these by hand in their real runtime:
   - The macOS slide title with quotes (bug 1).
   - Starting a session in the PowerPoint taskpane (bug 2).
   - First-run certificate trust on macOS and Windows (bugs 25 and 26).
   - `npm run dev` for the PowerPoint add-in (bug 28).
4. Fix behaviour changes to be aware of:
   - **Bug 34:** `parseDecisions` now forces `started=false` when confidence is below 0.7.
   - **Bug 35:** in the gauntlet, late flips no longer count as correct, so recall numbers will drop compared with earlier reports in `docs/gauntlet/`.
   - **Bug 8:** `current-session` now only answers requests from `https://localhost` origins. Check that the PowerPoint pane's origin matches.

## Suspicions not checked (rated 2/5, never sent to a prover)
These might be real bugs. Ordered roughly by how much they're worth checking:
- `apps/web/app/api/script/route.ts` PUT and `api/local/plan` POST (apply/probe) have no `requireEngine` auth check.
- `apps/desktop/main.js`:
  - The HTTPS proxy adds `ACCESS_PASSWORD` to every local relay request but never on the WebSocket upgrade.
  - `captureRegion` can crop past the image edge.
  - `reportProblem` can cut a `%XX` escape in half.
  - Nothing notices when cloudflared dies, so the old URL stays shown.
  - `download` doesn't handle a relative redirect.
  - `waitFor` accepts a 5xx response as ready.
  - `overlayUrl` doesn't URL-encode the code.
- `apps/desktop/slideshow.js`: osascript spawn failure triggers both the error and the close handler, so the polling loops double each time.
- `apps/desktop/stt.js`: `start()` hangs if the worker exits silently, and `ensureModel` has no guard against running twice at once.
- `apps/desktop/localai.js`: AMD APUs (`Radeon … Graphics`) are classed as discrete, and the recommended-model list gets reordered.
- `apps/web/components/Teleprompter.tsx`:
  - Cancelling during the mic probe still starts the STT backend.
  - The warmup and save requests send no auth headers, and save doesn't check `res.ok`.
  - Cloud mode silently falls back to browser STT.
  - The pre-opened mic isn't released when the engine stops itself.
- `apps/web/components/useScreenSense.ts`:
  - `watchStream` clears the desktop source the user just picked.
  - The stream leaks if `start` throws.
  - A log line repeats every second after the frame cap is reached.
- `apps/web/components/useSession.ts`: there's no dedup for concurrent `ensureEngineToken` calls, and an old token outlives unmount.
- `packages/stt`:
  - In `whisper.ts`, `stop()` drops the last audio window, and `start()` hangs if stopped mid-load.
  - In `openai.ts`, partial text gets mixed between items.
  - `browser.ts` ignores the language option.
  - `mic.ts` leaks the stream if AudioContext setup fails.
- `packages/core`:
  - `script.ts` treats `#1 priority` as a heading.
  - In `engine.ts`, committed segments are joined with no space, and the streak isn't reset when the section changes.
  - In `screen.ts`, `frameDiff` gives NaN when the length isn't a multiple of 4, and `hasPresenterCue` counts the same cue twice.
  - In `gauntlet.ts`, `pct` uses the upper median and the clock can run backwards.
  - In `clef.ts`, a bullet with id `fact_0` collides with a fact id.
- `apps/web/lib`:
  - `import/parse.ts`: double entity decoding, `<w:p/>` merging the next paragraph, and the plain-text heading and list handling.
  - `localModels.versionAtLeast`: prerelease versions and a `v` prefix.
  - `router.buildPlan`: picks cloud even when cloud was measured slower.
  - `sysinfo.cpuPercent`: race between concurrent calls.
  - `pii/guard.ts`: placeholder numbering can collide with Rizzo's keys.
- PowerPoint, browser extension and server:
  - `notes.ts` uses the same loose bullet regex as bug 23.
  - The manifest asks for PowerPointApi 1.4 but the code uses 1.5 APIs.
  - `SlidePos.title` is never set.
  - The adapters skip `svg` with the wrong tag case.
  - `server.ts` gets a NaN version on a patch with no version.
